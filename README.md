# 《哎呀，又月底了呀》

完全独立的8-bit浏览器小游戏，不依赖原有项目文件。

## 启动

直接打开 `index.html`，或在本目录启动任意静态文件服务器。

## 操作

- 电脑：WASD / 方向键移动，E / 空格互动。
- 手机：左下方向按钮移动，右下按钮互动。
- 卡片、菜单和数学题打开时暂停计时；确认行动后扣除对应时间。

## 当前内容

- 12个月、每月5分钟的游戏循环
- 单一小窝、动力和幸运系统
- 月初命运卡与永久图鉴
- 主工作三选一及数学题
- 每月一次兼职和临时工具
- 食物、娱乐、银行、股票、ROI与幸运商店
- 月底自动交租、利息、债务和破产机制
- 8-bit昼夜变化、键盘与手机控制、合成音效
- 简化环路地图、手机跟随镜头与不遮挡控制安全区
- 紧凑4:5收藏卡版式，每张卡都有独立像素插画、效果和数值区
- 月初防刷新恢复点（无手动存档）

所有持久化数据使用 `aiyaMonthEndGame_*` 前缀，避免与其他游戏存档混用。
